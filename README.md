# PEPO MUSIC SOUND

Proyecto académico de desarrollo web.

## Incluye
- Página de producto PEPO MUSIC SOUND.
- Investigación de JavaScript Vanilla, jQuery, JSON, hosting y dominios.
- Bootstrap 5 con diseño responsive.
- Bootstrap Carousel con `carousel-fade`.
- Animaciones y navegación suave con JavaScript.
- Modo claro/oscuro con `localStorage`.
- Página con 15 productos/experiencias de IA de Google.
- Cuestionario interactivo de 10 preguntas.

## Ejecutar
Abre la carpeta en Visual Studio Code y abre `index.html`. Para una experiencia local más cómoda puedes usar Live Server.

## Publicar
El proyecto es estático y puede desplegarse en Vercel o en otro hosting compatible con archivos HTML, CSS y JavaScript.

## Nota sobre las IAs de Google
La disponibilidad y las condiciones de acceso pueden cambiar por país, edad, cuenta, producto y plan. La página del proyecto evita afirmar que todas sean completamente gratuitas.
